# 🔐 Keylogger Program 🚀

A simple Python keylogger that records and logs keystrokes into a file. Includes timestamped logs, a custom stop command, and a manual stop mechanism.

---

## 🔹 Features

- ✅ Logs normal and special keys  
- ✅ Stores keystrokes in `keylog.txt`  
- ✅ Includes timestamps for each keystroke  
- ✅ Stops gracefully by typing `"keylogger_stop"`  
- ✅ Manual stop option using **Esc** key  
- ✅ Multi-threaded execution for smooth performance  

---

## ⚡ How to Run

### Step 1: Install Dependencies
Make sure Python is installed, then install `pynput`:

```bash
pip install pynput
```

### Step 2: Clone & Navigate
Clone this repository and move into the folder:

```bash
git clone https://github.com/yourusername/keylogger.git
cd keylogger
```

### Step 3: Run the Keylogger
Execute the script:

```bash
python keylogger.py
```

### Step 4: Stopping the Keylogger
- Type **`keylogger_stop`** anywhere to stop logging  
- Or press **Esc** to manually stop the keylogger  

### Step 5: Check the Logs
After stopping, open `keylog.txt` to view recorded keystrokes.
